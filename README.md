# thoughts-to-ai-real
-Using human written lyrics and AI as a prototyping tool for music for crowdsourcing music.


This project is not intended to promote AI slop, replace human efforts, or become a band. 
The open source nature of GitHub lends itself to a collaborative effort for lyrical production and musical remastering. 
If you have musical instrument skills you may fork the project, thus giving credit to all parties involved.
